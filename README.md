# 🚀 CollabMind – Collaborative AI-Powered Project Platform

**CollabMind** is a full-stack **AI-powered project collaboration platform** that merges the power of Trello, Notion, Slack, and Miro — all into one unified workspace.  
It enables seamless teamwork with **real-time collaboration**, **intelligent ideation assistance**, and **dynamic project management** — simplifying the way teams brainstorm, plan, and execute projects.

---

## 💡 Overview

This project was developed as part of my **Full Stack Development**, focusing on:
- Building **real-time communication tools**
- Integrating **AI-powered idea generation (Gemini API)**
- Designing a **scalable task management system** using modern web technologies.

CollabMind empowers teams to collaborate efficiently, innovate faster, and stay organized — all in a single, interactive environment.

---

## ⚙️ Key Features

### 🔐 User Authentication & Role-Based Access Control (RBAC)
- Secure login and signup using JWT.  
- Role hierarchy: **Admin**, **Manager**, and **Member** with custom privileges.  
- Fine-grained access to project creation, editing, and management.

### 🤖 AI Assistant (Gemini API)
- Generate new project ideas instantly.  
- Brainstorm creative solutions or summarize group discussions.  
- Embedded throughout the workspace for on-demand assistance.

### 📋 Kanban-Style Task Management
- Drag-and-drop interface for tracking project stages.  
- Create, assign, and update tasks dynamically.  
- Custom columns for “To Do,” “In Progress,” and “Completed.”

### 💬 Project-Based Real-Time Chat
- Threaded discussions per project.  
- Instant message delivery and notifications via **Socket.IO**.  
- Enhances communication without external chat tools.

### 🖊 Real-Time Whiteboard
- Collaborative workspace for sketches, flowcharts, and mind maps.  
- Supports drawing, erasing, and clearing boards in real-time.  
- Enables visual brainstorming for distributed teams.

### 📊 Analytics Dashboard
- Visual insights into **team productivity**, **project deadlines**, and **task distribution**.  
- Helps track efficiency and project performance trends.

### ⚙️ Admin Panel
- Centralized management of **users, roles, and projects**.  
- Easy control over member privileges and workspace settings.

## 🧠 Installation & Setup

Follow these steps to run **CollabMind** locally 👇

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/yourusername/collabmind.git
cd collabmind
```

### 2️⃣ Install Dependencies
```bash
cd frontend && npm install
cd ../backend && npm install
```

### 3️⃣ Start the Backend Server
```bash
npm run server
```

### 4️⃣ Start the Frontend
```bash
npm run dev
```

Your app will be live at:  
👉 **Frontend:** `http://localhost:5173`  
👉 **Backend API:** `http://localhost:5000`
